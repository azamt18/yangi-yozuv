# Launch texts

Copy-paste texts for the store and for announcing the extension.
The Uzbek text uses the *current* spelling (oʻ, sh, ch), because that's what readers search for and type today.

## Chrome Web Store: Russian listing

Add it in the dashboard under Store listing → language → Русский.

**Summary** (≤132 chars):
Печатайте на новом узбекском алфавите: sh→ş, ch→ç, oʻ→ö, gʻ→ğ автоматически.

**Description:**

```
Пишите на новом узбекском латинском алфавите так же, как привыкли.

С 22 апреля 2027 года вступает в силу новый алфавит: Sh → Ş, Ch → Ç, Oʻ → Ö, Gʻ → Ğ. Искать новые буквы на клавиатуре не нужно. Печатайте как обычно: Yangi Yozuv заменяет слово автоматически, когда вы его допишете.

  shahar → şahar
  choy → çoy
  oʻzbek → özbek
  togʻ → toğ

• Английские слова, ссылки, email и @username не меняются.
• Если расширение заменило лишнее, нажмите Backspace: слово вернётся.
• Список слов-исключений для имён и брендов.
• Работает в Telegram Web, Gmail, Facebook, Instagram, WhatsApp Web и на всех сайтах .uz. На других сайтах включается одной кнопкой.

Ничего не покидает ваш компьютер. Набранный текст никуда не отправляется: расширение вообще не обращается к интернету.
```
